# Language Islands

A contextual language-learning workspace built with Next.js, React, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Yarn also works if you prefer it: `yarn && yarn dev`.

Open [http://localhost:3000](http://localhost:3000).

## Planned services

- Firebase Authentication and Firestore for per-user data
- Vercel Route Handlers for secure translation requests
- DeepL as the first translation provider
- Additional translation and text-to-speech providers later

Never commit API keys. Local environment variables belong in `.env.local`.
